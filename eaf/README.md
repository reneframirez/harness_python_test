# eaf/

Carpeta de entrada con los PDF de "Estudio para análisis de falla" (EAF) del Coordinador Eléctrico Nacional,
por ejemplo `EAF_410-2026.pdf`.

Los PDF **no se versionan** (`.gitignore`): traen nombres, RUT y direcciones de representantes legales.
Copia aquí los PDF que quieras procesar; esta carpeta es la única entrada del programa.
Las pruebas automáticas usan texto sintético, nunca estos archivos.
